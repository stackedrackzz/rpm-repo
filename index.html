stackedrackzz RPM repo

A GPG-signed yum/dnf repository, built and published straight from this GitHub repo via GitHub Actions and served as static files by GitHub Pages.

1. Import the signing key

sudo rpm --import https://stackedrackzz.github.io/rpm-repo/RPM-GPG-KEY-stackedrackzz

2. Add the repo

sudo curl -o /etc/yum.repos.d/stackedrackzz.repo \
  https://stackedrackzz.github.io/rpm-repo/stackedrackzz.repo

3. Install packages

sudo dnf install hello-repo
